Getting Started

Import Your History

1. Locate your Spotify data export folder.

This is usually a .zip file received via email from Spotify's privacy dashboard.

2. Select only JSON files containing audio history.

We parse your listening patterns directly from these files.

3. Look for files named like 'Streaming_History_Audio_YYYY_N.json'.

Example: Streaming_History_Audio_2025_1.json

warning

Important: Do not upload video history files (e.g., 'Streaming_History_Video_YYYY_N.json'). These are currently not supported for analysis.
